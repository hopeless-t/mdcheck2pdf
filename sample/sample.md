# 作業手順サンプル

これは mdcheck2pdf のサンプルです。Markdown のチェックリストが、PDF 上で**実際に押せる欄**になります。

## 準備

- [ ] 道具を用意する
- [x] 材料を確認する（これは最初からチェック済み）
- [ ] 作業場所を片付ける

## 本作業

- [ ] 一つ目の工程を行う
- [ ] 二つ目の工程を行う。長い項目はこのように折り返されますが、欄は最初の行の先頭に付きます
- [ ] 結果を記録する

## 費用の目安

| 項目 | 目安 | 備考 |
|---|---|---|
| 材料費 | 数千円 | 店舗による |
| 道具 | 数万円〜 | 初回のみ |

- 普通の箇条書きはこの通り、ただの「・」になります
- **太字**もそのまま太字で出ます
