# mdcheck2pdf

Markdown のチェックリスト（`- [ ]`）を、**PDF 上で実際にクリックしてチェックできるフォーム欄**に変換するツール。

チェックリストは「文字の絵」ではなく、欄そのものとして PDF に埋め込まれます。PDF を開いたまま進捗を埋めて保存でき、印刷すれば紙のチェック欄としても使えます。手順書・点検票・受け渡し文書など、「埋めていく文書」のための道具です。

## 使い方

```bash
pip install fpdf2 pymupdf
python3 mdcheck2pdf.py input.md output.pdf
```

- 日本語フォント（TTC/TTF）が必要です。既定では Noto Sans CJK のパスを見に行きます。違う環境では `--font` / `--font-bold` で指定してください。
- 対応する記法: 見出し（`#`〜`###`）、太字（`**...**`）、箇条書き、番号なしリスト、表、チェックリスト（`- [ ]` / `- [x]`）。

## 仕組み（二段構成）

1. **レイアウト段（fpdf2）** — 本文を組版しながら、各チェック項目のページ番号と位置を記録する。
2. **差し込み段（PyMuPDF）** — 記録した位置に AcroForm チェックボックスを配置する。

本文の組版と、欄という「機能」を分離し、位置の記録だけで接続するのが要点です。☐ の字形を持たないフォントでも豆腐にならず、ビューア側で ON/OFF の見た目が正しく切り替わります。

## 検証方法

生成した PDF について、次を確認しています。

- フォーム欄（CheckBox）の個数が、元の `- [ ]` の個数と一致すること
- 欄の値を ON にして再描画すると ☑ が表示され、OFF では空の箱になること
- 全ページを画像化して目視で崩れがないこと

`sample/sample.md` から `sample/sample.pdf` を生成済みです。まずこれを開いて、欄が押せることを確かめてください。
